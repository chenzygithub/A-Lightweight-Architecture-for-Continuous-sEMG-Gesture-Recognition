Hardware: OYMotion gForcePro and OYMotion ROH-LiteS001 dexterous hand

Environment: PyTorch

Usage: Run the main file to start data acquisition; press the 'Q' key to stop once the acquisition is complete.
Next, press the 'W' key to initiate model training. 
Finally, press the 'E' key to enter real-time bionic hand control.
